# 女神回归文章配置与附件留存

共十二篇，原 PDF 包含原图、字体、版式、署名及结尾内容，源文件逐字节未改动。
封面另选正文代表图，未使用结尾卡片。网站阅读版采用提前渲染的连续高清透明分片，手机/电脑分别载入对应尺寸，按阅读位置加载并释放远处图片。不需要先下载、解析整份 PDF。
仅移除原 PDF 最底层的两块整页纸底矩形。没有白色像素抠图、没有修改照片或文字；原文图片中自带的白底、文字底色和结尾卡片全部保留。原 PDF 下载保持不变。

## 恢复方法

1. 把包内 assets/ 与 content/ 按目录结构合并到网站根目录。
2. 在文章发布器中用“导入 JSON”选择本包的文章配置 JSON。十二个稳定 ID 可重复导入更新。
3. 网站需保留 pdf-inline-viewer.js、pdf-prepared-reader.js、app.js、styles.css 和 cosmic-refinement.css 的支持。styles.css 中的普通文章图片宽度限制必须排除 .pdf-prepared-image，否则桌面端分片底部会留下空隙。本包 viewer-support/ 留有本次代码快照；不同版本网站应先比较再合并，不要直接覆盖。更新脚本/样式时一并更新 HTML 的缓存版本号。
4. 这份配置只恢复十二篇文章，不覆盖其他文章、评论或站点设置。

附件路径是网站相对路径；仅留存 JSON、未复制附件，会导致新设备无法显示 PDF/封面。
第一篇原 PDF 为 45,869,840 字节。本地与 ZIP 留有完整原件；GitHub/Cloudflare Pages 使用 content/goddess-return/01/original.part-*.bin 无损分段，以及 functions/content/goddess-return/01/original.pdf.js、pdf-chunk-response.mjs、goddess-pdf-parts.mjs 实时按需拼接，支持下载与 Range 断点读取，原下载地址不变。部署到 Pages 时不要把第一篇完整 original.pdf 加入部署目录，它超过单文件限制；其余十一篇可直接部署。使用普通静态服务器时，可直接使用 ZIP 中的完整原件。

## 重新生成

安装构建工具依赖 @napi-rs/canvas、sharp（或令 SIRIUS_RENDER_RUNTIME 指向已有依赖目录），运行 node build-goddess-reader.cjs，再运行 node prepare-goddess-deployment.cjs。生成文件使用内容哈希命名，浏览器可安全长期缓存。重新导出留存包时包含校验清单中的所有附件及阅读器/下载路由。
