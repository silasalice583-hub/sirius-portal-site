# 星空视觉与 PDF 阅读优化计划（最终需求版）

以 2026-09-26 最后一次补充为准，取代早先的半透明玻璃框、18px 点击图标及标题两行截断方案。

## 实施顺序

1. 首页和框架：全屏入口、勋章在标题上方；扩大勋章与翠绿色代码流体标题并拓宽字距。地球与指定天狼星 A/B 艺术图双层淡入轮播，绿色代码位于照片上方、文字下方，照片延伸至透明页尾。
2. 插画：内置 imagegen 生成透明星座与简洁钢笔/点击图标，保留 Alpha、检查孔隙与边缘。点击图标按最新要求 24px，钢笔 36×54px。天狼星位置使用用户指定的薰衣草紫/金色天行者徽记。
3. 分类和导航：放大透明星座，拖动、滚轮、触屏滑动、箭头或键盘切换分类；分类停靠时更新背景，不修改后台文章分类顺序。页码窗口随当前页移动，保留首尾页。
4. 阅读页：普通容器透明、保留曲线边缘与文字轮廓；门户更新/访谈/会议仅横铺封面，不重复标题，其他分类完整换行。封面丢失时恢复标题。PDF 原纸面、作者配色及矢量文字不随背景染色。
5. 冥想和关于：入口统一为“参加集体冥想”；集体场域及页尾透明。生命之花使用确定的六角格点圆阵、径向渐变花瓣与光流，避免任意手绘圆阵。导航及换页控件使用星空矢量图形，XP 灵感短转场。
6. 功能：修复音乐按钮反馈，以真实播放状态触发上浮音符；没有音源时提示配置。修复 PDF 发布时本地附件未上传、保存状态误阻止重建、老移动引擎兼容、懒加载与资源释放。
7. 验证及交付：桌面/手机相同功能与独立尺寸图片；自动化检查分页、封面模式、媒体迁移、PDF 内存上限和字色；只同步程序及正在使用的压缩素材，不上传用户未发布的原始文档。

## 边界与验收

- 不改动线上文章内容或后台设置，不自动添加来历不明的背景音乐。
- PDF 页面不是网站文字框，其原稿底色必须保留。
- 使用高分辨率原图，不把低分辨率图片插值冒充新观测。摄影来源及艺术图例外见 assets/space/README.md。
- 大型背景仅两个照片层；隐藏标签暂停轮播，减少动态效果设置停止装饰动画。
- 本轮自动化、图片和 PDF 样本检查记录见 docs/visual-and-pdf-refinement.md。浏览器连接超时的部分必须明确标记未复测。
